## 0. 口径与术语

**0.1 三型是 atlas 的工作分类，不是行业标准分类。** 中文印刷字体的通行分法是「宋、黑、仿宋、楷」四大基础印刷体 [13][14]。本文件的三型（粗黑无衬线 / 新中式 / 复古旧字体）按设计场景需要横切这四类，用结构特征判定归属，不用字体名定义类型。对照关系如下：

| 三型 | 主要来自的传统类别 | 不属于本型的同类字体 |
| --- | --- | --- |
| 粗黑无衬线 | 黑体的 Bold 以上字重（含圆体、窄体等变体）[13] | 同一黑体家族的 Light / Regular 字重 |
| 新中式 | 现代数字化的宋体、仿宋、楷体中，笔画经过规范化整理的字库 [14] | 保留刻模毛边或旧字形的复刻字库（归复古型） |
| 复古旧字体 | 活字 / 刻本复刻字库；照排与手绘时代的美术字数字化 | 仅加了做旧滤镜的现代字库（不归任何一型，见 §6） |

**0.2 结构术语（atlas 操作定义）。** 以下 6 项是 §1 定义与 §2 判据的观测维度，观察时字号不小于 48 px（或打印 36 pt），同一字重。

| 术语 | 操作定义 | 怎么看 |
| --- | --- | --- |
| 笔画末端 | 横、竖、撇、捺收笔处的形状 | 平切 / 圆头 / 三角饰角 / 尖锋 / 墨迹毛边 / 几何折线 |
| 字怀 | 笔画围合出的内部留白 | 看「口」「日」「国」的内白面积与笔画黑面积之比 |
| 重心 | 字的视觉重心高度 | 看「日」「目」中间横画的位置是否高于几何中线 |
| 中宫 | 字心部件向中心聚拢或向外撑开的程度 | 看「国」外框与字身框的距离、「永」四周笔画的伸展 |
| 对比度 | 同一字内最粗笔画宽度 ÷ 最细笔画宽度 | 目测或放大后量取 |
| 字面 | 字形实际占用字身框的比例 | 看全包围字外框离字身框边缘有多远 |

## 1. 三型结构定义

| 维度 | 粗黑无衬线（`cn-heavy-sans`） | 新中式（`cn-neo-chinese`） | 复古旧字体（`cn-retro`） |
| --- | --- | --- | --- |
| 笔画末端 | 平切或圆头，无字脚；黑体本义即「笔画厚度均匀，平笔无节」[13] | 带书写或刻写来源的收笔：横末三角饰角、撇捺尖锋出锋（宋体「横细竖粗撇如刀」「横末带小三角」[14]），或楷书提按；边缘经数字化整理，线条干净 | 两支：活字 / 刻本复刻支保留刻模与印痕特征（饰角钝、轮廓不均）；美术字支用几何构件替换书写笔画（如综艺体以拐弯直线代撇捺 [13]） |
| 对比度 | 低：横竖视觉等粗；极粗字重下横画常略细于竖画以作视觉补偿 | 中到高：横细竖粗，或楷书式粗细渐变 | 活字支中高且逐字不均；美术字支常把对比推向极端（极粗、交叠反色 [13]） |
| 字怀 | 大，字内留白被笔画厚度压缩但结构上开放 | 中到小 | 活字支偏小；美术字支因几何化而饱满 |
| 重心 | 居中或略高 | 偏高，字形常偏修长 | 不统一（手工刻模或手绘带来的逐字差异） |
| 中宫 | 放开，部件撑向字身框 | 收紧，外围撇捺舒展（内紧外松） | 活字支字面偏小、字距疏；美术字支按装饰需要改变部件比例 |
| 字形标准 | 现行规范字形 | 现行规范字形 | 常见旧字形 / 传承字形（如一点明体按《传承字形部件检校表》制作 [10]） |
| 一句话定义 | 以笔画厚度制造黑白对比的标题黑体 | 把书写或刻本笔意规范化后的现代字库 | 保留某一历史生产方式（活字、刻本、美术字）痕迹的字体 |

## 2. 每型判据（看字样答「是 / 否」）

**归属规则：** 某型判据答「是」≥ 3 条即归该型；若同时满足新中式与复古型各 ≥ 3 条，以 R-2 或 R-4 是否为「是」裁决（是则归复古型）。三型都不足 3 条时记为「三型之外」（例如书法手写体、像素体），不强行归类。

### 2.1 粗黑无衬线

- H-1 横、竖、撇、捺的收笔全部是平切或圆头，整字找不到三角字脚与尖锋出锋吗？
- H-2 同一字内最细笔画的宽度不小于最粗笔画的一半（对比度 ≤ 2）吗？
- H-3 「口」「日」「国」的内部留白面积小于或约等于围合它的笔画黑面积吗？
- H-4 「国」「图」的外框几乎贴到字身框边缘，整字轮廓接近正方形吗？
- H-5 把同一字重缩到 12–14 px，「量」「解」这类多笔画字的内部留白已糊成黑块吗？（是 = 该字重只为标题尺寸设计，符合本型）

### 2.2 新中式

- N-1 横画收笔处有三角饰角或顿笔，而饰角轮廓是干净的直线或光滑曲线、没有墨迹毛边吗？
- N-2 撇、捺或长横的末端收成尖锋或刀形出锋吗？
- N-3 最粗笔画宽度达到最细笔画的 3 倍以上，或能看到楷书式的连续粗细渐变吗？
- N-4 全包围字的外框明显缩进字身框，而「永」「春」的撇捺却伸到接近字身框边缘吗？
- N-5 同一字重内任取 20 个字，饰角的大小和角度保持一致吗？

### 2.3 复古旧字体

- R-1 出现与现行规范字形不同的旧字形或传承字形部件写法吗？
- R-2 放大到 200 pt 以上，笔画轮廓可见非均匀的起伏、印痕扩张，或同一种饰角在不同字里形状不同吗？
- R-3 相同部件（如「氵」「口」「讠」）在不同字里的大小或位置有可察觉的不一致吗？
- R-4 撇、捺或弯钩被替换为折线、直角、整圆弧等几何装饰构件吗？
- R-5 默认排列时字面明显小于字身框、行内字距比现代正文字库更疏吗？

## 3. 场景矩阵

「适用」= 可作首选；「慎用」= 可用但须满足括注条件并在交付说明中写明理由；「不用」= 本型结构与场景要求冲突。

| 场景 | 粗黑无衬线 | 新中式 | 复古旧字体 |
| --- | --- | --- | --- |
| 海报标题 | **适用**：大字号下笔画厚度给出最强的远距黑白对比 | **适用**：高对比在大字号下完整呈现，适合文化与人文主题 | **适用**（内容须有对应年代或出处语境）：字体本身携带年代信号 |
| 长文正文 | **不用**：本型按定义是标题字重，正文字号下字怀闭合（H-5）；正文改用同家族常规字重，那已不属于本型 | **慎用**（仅限为正文设计的字重，如宋体正文字重）：标题化的高对比、修长变体在小字号下细横画会消失 | **慎用**（仅活字复刻支中为正文设计的字库，例如朱雀仿宋以正文仿宋为目标 [8]）；美术字支不用 |
| 界面 UI | **慎用**（仅大数字、页面级标题）：导航与控件文字需要可缩放的常规字重 | **不用**（例外：单屏品牌标题，须写明理由）：细横画在低像素密度与小字号下断裂，信息密度越高越难读 | **不用**：部件不一致与轮廓起伏在 UI 小尺寸下会被读成渲染错误；旧字形与用户输入的规范字形不一致 |
| 包装 | **适用**（仅品名与卖点）：货架距离下的识别；成分表等小字不用本型 | **适用**：需要书写意味的品名（茶、酒、文化礼品等） | **适用**：老字号、复刻包装；小字说明仍用现行规范字形字库 |
| 演示文稿 | **适用**：投影远观时的标题页与断言句 | **慎用**（限章节页标题并放大字号）：投影与压缩会吃掉细横画 | **慎用**（限引用页、年代标注页）：通篇使用会让年代信号盖过信息层级 |

## 4. 代表字体与授权状态

**4.1 授权状态词表（与计划书 §5.1 第 4 条一致）**

- **开源 OFL**：以 SIL Open Font License 1.1 发布。许可允许使用、嵌入、修改、再分发，并可随软件捆绑出售，但字体文件本身不得单独出售；修改版不得使用保留字体名 [1]。
- **开源（其他许可）**：以非 OFL 的开放许可发布，逐条写明许可名。
- **免费商用**：权利人官方页面明文允许免费商业使用；须同时写明官方限定的使用方式（例如方正仅对「发布使用」免费 [11]）。
- **需购买 / 授权**：权利人官方页面明文要求商业使用须另行取得授权。
- **未核**：未能在官方来源读到许可正文。一律不得写成可商用。

## 5. 与西文搭配（只写「三型各配哪类西文」这一层）

西文类名借用 Vox-ATypI / BS 2961 的术语作为描述词汇；ATypI 已于 2021 年停止采用该分类，故这里只把类名当作通用词汇，不当标准 [15]。

| 三型 | 配哪类西文 | 结构理由 |
| --- | --- | --- |
| 粗黑无衬线 | Lineal 中的 Neo-grotesque 或 Grotesque，取相近的粗字重 | 双方都是低对比、平切收笔，黑度可以对齐 |
| 新中式 | Garalde 或 Transitional 衬线；需要小字辅助信息时可配 Humanist lineal | 衬线的笔画对比与三角饰角可呼应中文的横细竖粗与饰角 |
| 复古旧字体 | 活字复刻支配与原字模年代相近的衬线（按年代在 Garalde / Transitional / Didone 中选）；美术字支配 Mechanistic（粗衬线）或粗字重 Grotesque | 让两种文字指向同一历史生产方式 |

**邻接分工：** 具体字体配对、字号与字重组合交给 `font-pairing-suggester`；字体栈、行高、字重、字距等渲染参数交给 `chinese-typography-system`（其 `SKILL.md` 第 1–51 行只覆盖这些参数，见 `差集比对-20260928.md` 附表）。atlas 不重复两者的内容，overlay 见 `overlays/chinese-typography-system.md`。

**系统字体栈不等于三型：** PingFang SC、Microsoft YaHei、Noto Sans CJK SC 这类系统栈属于为渲染稳定而选的无衬线，不等同于本文的「粗黑无衬线」气质选择（合并自 c61ed7d 版 §3 末；「`chinese-typography-system` 使用这组系统栈」为 c61ed7d 作者转述，待落盘复核）。

## 6. 反模式

### 6.1 粗黑无衬线

- H-AP-1 把 Heavy / Black 字重设为长文正文，正文区域在阅读距离下成为一块均匀黑灰。
- H-AP-2 用软件的「仿粗体」按钮把常规黑体伪造成粗黑，笔画在转折处变形，且印刷时与真实粗字重的黑度不一致。
- H-AP-3 粗黑标题再叠加描边或外发光，本已被压缩的字怀被第二次吞掉，「量」「解」一类字无法辨认。
- H-AP-4 粗黑中文与极高对比的 Didone 西文粗体并排在同一行，一侧等粗、一侧发丝线，行内黑度断裂。

### 6.2 新中式

- N-AP-1 在表格、表单、后台列表等高信息密度界面使用新中式字体，细横画在 12–14 px 下断裂或消失。
- N-AP-2 把书法手写墨迹当作新中式字库使用而不检查 N-5；手写体不属于三型，须按「三型之外」单独说明。
- N-AP-3 新中式标题改为竖排时仍沿用横排标点和横排字距，标点方向错误，外展的撇捺与下一字相撞。
- N-AP-4 把新中式标题的字距收到与黑体标题相同的紧度，内紧外松的结构失去呼吸空间，撇捺交叠。

### 6.3 复古旧字体

- R-AP-1 内容与任何历史年代无关（例如科技产品发布会主标题）时使用复古型，年代信号成为噪声。
- R-AP-2 把美术字支用于超过一行的连续文本，几何折线替换的撇捺在连续阅读中拖慢识别。
- R-AP-3 活字复刻字库缺字时由系统回退到现行规范字形字库补字，同一行并存两套字形标准。
- R-AP-4 给现代规范字库叠加做旧纹理冒充复古型：随机噪点不符合 R-2 所说的刻模逻辑，且 R-1、R-3 均不满足。
