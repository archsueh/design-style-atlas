# 中文字体分类三型 × 场景

激活：`style: ref/cn-type`

本机检索（`~/Developer` + `~/Documents/Code/skill-hub`，排除 `node_modules`）对「中文字体分类 / 字体气质 / 黑体.*宋体.*楷体 / 中文.*字体.*场景」为 0 命中。`chinese-typography-system` 只管渲染参数，不管气质分类。本文件补这一层。

分类按**结构特征**，不以字体商品名定义类型。未核实授权的字体标「未核」，不得写成可商用。

## 1. 三型定义

### A. 粗黑无衬线

结构：笔画末端截平或微凹，几乎无衬线；横竖粗细对比弱；字怀匀、中宫偏满；重心居中略偏上；转角简化，少内折。

看字样归属（须同时满足 ≥3 条）：

1. 主标题在远距（约 3 米看 1 米高画面）仍能辨认单字轮廓。
2. 同一字重下，横画与竖画的视觉宽度差小于竖画宽度的 30%。
3. 内白（口、日、目）接近方形，不呈细长楷书内白。
4. 无装饰起笔、无飞白、无刀刻感斜切。

### B. 新中式

结构：保留毛笔起收的方向感（横画右上斜、竖画垂而微弯），但去掉碑帖繁笔；中宫比粗黑更收；横细竖粗对比中等；结构贴现代阅读（字面偏满、不靠书法章法布白）。

看字样归属（须同时满足 ≥3 条）：

1. 能指出至少一处「笔锋方向」（横的右上斜或捺的展开），不是纯几何截笔。
2. 对比度高于粗黑、低于复古木刻/铅印体。
3. 用于横排标题时，字距可紧到字面相切而不糊成墨块。
4. 不用繁体异体、不用竖排古文标点作为「中式」信号。

### C. 复古旧字体

结构：复刻铅印、木刻或早期照相排字：字身有颗粒/缺口/墨涨；笔画对比可以很大；中宫或松或刻意不匀；常带衬线、三角饰、或宋体横细竖粗的印刷结构。

看字样归属（须同时满足 ≥3 条）：

1. 在 200% 放大下能看到非平滑的边缘（模拟印迹），或明确的旧宋/旧黑结构。
2. 横竖对比明显高于 UI 黑体。
3. 用于长文小字时阅读效率下降（这是特征，不是缺陷）——故默认不当正文。
4. 装饰来自印刷史（衬线、字肩、墨点），不是霓虹或手写花体。

## 2. 场景矩阵

| 场景 | 粗黑无衬线 | 新中式 | 复古旧字体 |
|---|---|---|---|
| 海报标题 | 适用：短词、远距识别 | 适用：文旅/国潮主标题 | 适用：怀旧主视觉；慎用在需要国际流通的品牌主色旁边 |
| 长文正文 | 慎用：粗黑作正文易闷 | 慎用：新中式正文需选对比弱的一款 | 不用：阅读负担高 |
| 界面 UI | 适用：短标签、按钮；正文用常规黑体而非「粗」档 | 不用：笔锋在 12–16px 会糊 | 不用 |
| 包装 | 适用：货架远距品名 | 适用：国潮/文创主名 | 适用：茶饮/潮牌主名；用法规小字仍用无衬线 |
| 演示文稿 | 适用：一页一词 | 慎用：多页连续易腻 | 不用：投影锐度差时颗粒变成脏边 |

理由一句话：粗黑拼识别，新中式拼文化语义，复古拼时代气味。场景要的不是那一口气味时，不要用对应型。

## 3. 代表字体与授权

授权以厂商/开源许可证页为准，本表只标状态。

| 型 | 字体 | 授权 | 备注 |
|---|---|---|---|
| 粗黑无衬线 | Source Han Sans / Noto Sans CJK | 开源 OFL | 可变字重；作系统默认候选 |
| 粗黑无衬线 | HarmonyOS Sans SC | 未核 | 华为发布条款需按使用场景再核 |
| 粗黑无衬线 | Alibaba PuHuiTi | 未核 | 阿里普惠有独立授权文本 |
| 新中式 | Source Han Serif / Noto Serif CJK | 开源 OFL | 宋体结构，新中式里偏「印刷宋」而非毛笔 |
| 新中式 | LXGW WenKai | 开源 OFL | 楷体方向，标题可用、UI 不用 |
| 新中式 | 站酷庆科黄油体 等网盘字体 | 未核 | 不得在未核前当商用推荐 |
| 复古旧字体 | 思源宋体 Heavy + 故意做旧 | 开源 OFL + 后期效果 | 做旧是后期，不是字库本身 |
| 复古旧字体 | 各类「老宋/铅印」商业字 | 需购买 | 未购买不得嵌入 |

`chinese-typography-system` 的系统栈（PingFang SC / Microsoft YaHei / Noto Sans CJK SC）属于**渲染稳定用无衬线**，不是本三型的气质选择。

## 4. 与英文搭配

只写「三型配哪类西文」，具体配对交给 `font-pairing-suggester`（若已装）与 `overlays/chinese-typography-system.md`。

- 粗黑无衬线 →  Grotesque / Neo-grotesque（Akzidenz、Helvetica、Inter）。不要配花体。
- 新中式 →  人文主义无衬线或温和衬线（Source Serif、一个衬线 display）。不要配几何无衬线当主英文标题。
- 复古旧字体 →  旧衬线或木刻英文字（Clarendon、老式 Didot 的克制用法）。不要配几何未来感无衬线。

## 5. 反模式

- 粗黑：把 ExtraBlack 用满整段说明文字。
- 新中式：靠「繁体字 + 竖排 + 印章 PNG」冒充结构特征。
- 复古：用滤镜做旧一套现代黑体，边缘脏但结构仍是 UI 黑体。
- 三型混用在同一层级（主标题粗黑、副题新中式、装饰复古）而无主次。
- 未核授权的字体写进交付清单。
